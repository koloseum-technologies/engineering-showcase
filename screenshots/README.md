# Screenshots

These are curated screenshots of completed Koloseum MVP services, taken from locally seeded data and never from the production database. Mobile users are expected to make up the majority of the user base, so screenshots are taken on a phone viewport.

**Size:** 53 curated files / ~3.5MB (21 light + 21 dark product frames, plus 11 wireframe artefacts).

## Naming

```text
screenshots/
├── lounges/{account,operations,staff}/…
├── players/sessions/…
└── wireframes/players/sessions/…
```

Product captures are WebP. Sequence prefixes (`01-`, `02-`, …) follow the workflow order. Filenames are kebab-case.

Each frame is named with a theme suffix (`-light` / `-dark`). Wireframes have no theme variants.

## What is here

As of August 2026:

**Product UI (mobile viewport, 1082×2402, WebP, light and dark):** `lounges-operations`, `lounges-staff`, `lounges-account`, `players-sessions`.

**Wireframes:** desktop-oriented session flow (`01-select-lounge` … `06-checking-out`) plus other frames. These are the desktop-width elements in the set.

**Outstanding:** `players-competitions`, `players-account`, `backroom-compliance`, `backroom-staff`, `public-legal`, `public-help`, `public-landing`.
